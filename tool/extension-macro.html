Web Automation Macro

A small independent automation extension: record any sequence of browser steps as a reusable macro, edit it anytime, and it keeps going even if the page reloads.

🔧 Main Features

Important Note: All core portal automation (uploading estimates, e-MB bills, variations, and downloading data) is built directly inside our Excel Tool. This browser extension is an extra, optional, lightweight utility.

Record Steps

Record a sequence of steps on any website and save it as a re-usable workflow.

Edit Mode

Edit a recorded workflow at any time — tweak existing steps or add new ones without re-recording from scratch.

Reload Support

No matter how many times the page reloads mid-run, automation continues exactly where it left off.
